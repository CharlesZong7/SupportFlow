### 本轮问题和验收目标

如何让一个问题经过服务端校验、规则路由、受控模拟工具，返回可解释的结果，并明确说明没做什么？本轮目标不是四角色协作，而是为后续模型替换保留一条可测试的业务链。

初始 `D:\multi agent` 为空，没有项目、用户笔记、Git 仓库或适用 AGENTS.md。未发现 Docker、Podman、psql、redis-server 命令，也没有常见路径的 Docker 可执行文件；这不等同于扫描所有磁盘证明软件绝对未安装。Python 3.12.5；现有 FastAPI/Pydantic/Uvicorn/HTTPX 可复用；LangGraph 1.2.9 可导入，暂不用。PostgreSQL、Redis、ARQ 和数据库驱动未就绪，本轮没有依赖它们。

### 真实关键流程

`POST /api/support → SupportRequest 校验 + get_principal → SupportService.handle → validate_scope → route_request → ReadToolRunner.call → MockReadTools → SupportResponse`

咨询调用一次 `search_documents`。故障排查必须有 `symptom`，按资料、状态顺序调用两次工具；这不是并发查询。补问、未知意图、工单草案都有提前返回点。无资料时停止，不再读取状态。未知意图/无资料的 `needs_human` 只是业务结果，没有外部人工协作系统。

### 设计取舍

1. **先规则，后模型。** 用显式字段和有限关键词规则路由；暂不让模型决定访问权限或执行操作。普通函数没有被称为 Agent。
2. **先只读，后写入。** 工单草案包含精确的 action、产品、版本、请求人、标题、描述，但没有确认或创建接口。响应明确 `execution_available=false`，不产生业务副作用。
3. **身份来自服务端映射。** 请求体不接收用户 ID。公开演示凭据由服务端映射为 Principal，API 服务和工具都检查权限。只验证产品版本访问；私有工单归属验证留待资源实际建立。
4. **按准确版本返回资料。** 版本未知直接拒绝，不悄悄用最新版本。检索同时限制主题，修正了“登录超时误命中导出版本说明”的规则风险。
5. **异步契约不等于并发能力。** 模拟读取没有真实网络等待，`async def` 只保留适配器形状。故障注入的 `asyncio.sleep` 用于验证可取消的等待；不能当作真实 I/O 性能证据。
6. **先限定执行，不做恢复。** 工具 0.5 秒、只读阶段 2 秒，最多执行两次工具，单次一次尝试，零重试。失败不伪造状态；取消继续传播。执行记录只在响应中，无持久化。
7. **不引入无需求的组件。** 没有安装额外数据库，也没有提前搭 Worker。LangGraph 在角色协作进入验收范围时再使用。

## 2026-10-24 · Yuxi 阅读与完成体比较

本次问题：Yuxi 当前实际是什么类型的系统，我们的 M0–M4 完成体在功能、技术密度和整体复杂度上如何与之比较？本轮为源码阅读，不是新的开发里程碑。

- 用户提出阅读与比较要求；AI 通过 GitHub 连接器固定 `main@928141ceb2799cee18bcdbc060618ab9151ba48b`，核对 MIT 许可证，读取 README、架构、Compose、目录和关键实现片段，补记 [参考阅读-Yuxi](参考阅读-Yuxi.md)。未引入上游代码。
- Yuxi 的整体范围是通用知识智能体平台，覆盖知识库、图谱、可配置 Agent、子运行、Skills/MCP、沙盒、权限和运行管理；本项目聚焦技术支持与工单。
- 抽查到的真实提交链是 `submit_agent_request → _persist_request → db.commit → enqueue_agent_run`；子任务经过 middleware 工具和 `SubagentRunService.start` 持久化后投递；Worker 先取得 Run lease 再执行。不是把四个普通函数命名为 Agent。
- 一个关键设计取舍：过期 lease 会收敛为 `failed/worker_lease_expired`，外部副作用仍可能需要核对；“可靠执行”不等于任何任务均可自动无损继续。我们的工单写入要单独实现业务幂等与已保存结果查询。
- 比较结论是设计分析：完成 M0–M4 后，可以在角色边界、版本证据校验、审批与幂等上形成技术深度；功能广度、平台化和整体集成复杂度仍小于 Yuxi。没有性能或质量优于 Yuxi 的证据。
- 实际验证：仅来源、路径、关键代码与许可核对；没有运行 Yuxi，没有执行其测试，也未重跑本地 M0 测试。业务实现仍停在 M0。
- 待理解内容：模型调用子 Agent 与后台任务调度的区别；提交后投递的补偿窗口；lease 与外部业务幂等各保护什么。用户笔记和复述后续追加，当前不假定已掌握。
