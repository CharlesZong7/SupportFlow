## 已执行测试

运行命令见 README。`validation/m0-unittest.txt` 保存 22 项测试实际输出；`validation/m0-http.json` 保存独立 Uvicorn 进程返回的 7 个业务/拒绝案例及环境版本。测试耗时只属于本地 mock，不作为模型/业务性能指标。

| 场景 | 实际结果 |
| --- | --- |
| 简单导出咨询 | 一次资料调用，`answered`，返回匹配版本的手册证据 |
| 导出超时 + 现象 | 顺序两次调用，三条模拟证据及固定 `degraded` 状态 |
| 1.0 / 1.1 资料不同 | 各自返回 1000 / 5000 行，无跨版本证据 |
| 缺产品/版本/现象 | `needs_info`，无工具调用 |
| 未知产品/未知版本 | HTTP 400，无自动版本替换 |
| 无有效凭据 | HTTP 401 |
| bob 访问 1.1 | HTTP 403；直接调用工具也被拒绝 |
| 请求体注入 user_id/confirmed/mode | HTTP 422 |
| 空白问题 | HTTP 422 |
| 显式 troubleshooting 缺现象 | 仍补问，不能绕过字段要求 |
| 无法识别的意图 | `needs_human`，无工具调用 |
| 登录超时无匹配资料 | `needs_human`；不会使用导出资料或调用状态 |
| 创建工单请求 | 仅准确草案，真实创建次数为零（没有写工具） |
| 状态工具失败 | `tool_error`，保留已查资料，没有状态结果或私有异常文本 |
| 单工具超时 | `tool_error`，`timeout`，等待被取消并清理，无重试 |
| 只读阶段超时 | `tool_error`，在途工具标记 `cancelled` 并清理 |
| 工具预算耗尽 | 后续适配器不被执行，记录 `budget_exceeded` |
| 主动取消 service 协程 | `CancelledError` 继续传播，等待被清理 |
| 同时提交三次请求 | request_id 不同、预算各自独立；不属于压力测试 |
| 本地真实 HTTP | 健康/HTML/OpenAPI + 7 个 API 案例均通过，临时进程关闭 |

## 明确未验证及恢复边界

- 模型效果、模型输出格式、错误重试、模型不可用尚未验证；没有真实模型决策。
- 无四角色编排、并发工具读取、证据冲突复核、单 Agent 对照评测。
- `asyncio.timeout` 只在协程可让出执行时生效；未验证同步阻塞工具，未来不能直接放入事件循环。
- 只读阶段预算不是覆盖网络接收、鉴权等所有步骤的整请求硬超时。应用层无自动重试。
- 客户端断线是否取消服务端协程尚未验证；服务端主动协程取消测试不能替代它。
- 状态只在当前请求内存在。刷新/重启/取消后不提供结果查询；`request_id` 不具备恢复语义。
- 尚无私有工单、历史工单查询或持久化对象，普通用户之间的资源归属隔离未验证。
- 写操作、参数变更后重新确认、持久化确认绑定、重复消息幂等、成功响应丢失查询均未实现。
- 未验证外部服务、容器、PostgreSQL/pgvector、Redis/ARQ、MCP、SSE、部署和模型端到端性能。
